# Web Traffic Source Analysis

**EDAV Course-End Project**
Exploratory Data Analysis & Visualization (22ADC31N)

## Overview

This project explores the characteristics associated with website traffic and user engagement using exploratory data analysis, statistical summaries, and data visualization.

## Dataset

The project uses a **Web Traffic** dataset containing session-level website activity and engagement features. It includes information such as page views, session duration, bounce rate, traffic source, time spent on the page, previous visits, and conversion rate.

**Key performance variable:** `Conversion Rate`

The dataset must be uploaded separately to Google Colab before running the notebook.

## Tools and Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Notebook

Open `web_traffic_analysis.ipynb` in this repository to view the analysis, code, outputs, and visualizations.

To run the notebook, open it in Google Colab, upload `website_wata.csv` when prompted by the notebook's data-loading cell, and run the cells in order.

## Project Objectives

- Examine the distribution of website traffic and engagement metrics.
- Explore different traffic sources and their characteristics.
- Compare website performance across traffic sources.
- Investigate relationships between traffic, engagement, and conversion metrics.
- Analyze web traffic trends using grouping and time-series operations.
- Communicate findings through visualizations.

## Note

The analysis identifies descriptive patterns and associations between traffic sources, engagement metrics, and conversion performance. It does not establish causal relationships between traffic sources and website performance.
